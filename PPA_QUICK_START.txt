💡 WHAT IT DOES
═════════════════════════════════════════════════════════════════════════════

Instead of just seeing:
  ┌─ Candle
  ├─ OHLC: O=1, H=5, L=0, C=3
  └─ No intrabar details

You see the REAL PATH:
  ┌─ 1 (Open)
  ├─ 5 (High - hit first at 10:02)
  ├─ 0 (Low - hit second at 10:04)
  ├─ 3 (Close)
  └─ Connected as: 1→5→0→3


🎯 KEY FEATURE: High/Low Order Detection
═════════════════════════════════════════════════════════════════════════════

The indicator automatically determines:

Path Type 1:  O → H → L → C  (High reached first)
Path Type 2:  O → L → H → C  (Low reached first)

How? Uses M1 lower-timeframe data to check which price level
was reached first during the candle.


⚙️ MAIN SETTINGS (Easy to understand)
═════════════════════════════════════════════════════════════════════════════

Display Mode: Where to show the path
  ├─ 0 = On the chart itself (Default - easiest to see)
  ├─ 1 = Below chart (sub-window)
  └─ 2 = Separate window

ShowPath: Show the line? (true/false)
  └─ Default: true

PathColor: Line color
  ├─ clrDodgerBlue (Default - light blue)
  ├─ clrRed
  ├─ clrGreen
  └─ Any MT5 color name

PathWidth: Line thickness
  ├─ 1 (thin) - 2 (normal) - 3 - 4 - 5 (thick)
  └─ Default: 2

ShowPoints: Show O/H/L/C dots?
  ├─ true = Yes, show dots (Default)
  └─ false = No dots

PointSize: Dot size
  ├─ 2 (small) - 3 (normal) - 4 - 5 (big)
  └─ Default: 3

LowerTimeframe: Where to get High/Low timing
  ├─ PERIOD_M1 (Best accuracy - Default)
  ├─ PERIOD_M5
  └─ PERIOD_M15 (Less accurate)

CandlesToAnalyze: How many recent candles to show
  ├─ 1 = Last candle only
  ├─ 5 = Last 5 candles (Default)
  └─ 10 = Last 10 candles

ShowInfo: Show text info on chart?
  └─ true/false (Default: true)


🎨 VISUAL GUIDE
═════════════════════════════════════════════════════════════════════════════

Color codes for points:

  🟢 GREEN (O)     = Open
  🔴 RED (H)       = High
  🔵 BLUE (L)      = Low
  🟠 ORANGE (C)    = Close

The line connecting them is whatever color you set (PathColor).

⚠️ IMPORTANT NOTES
═════════════════════════════════════════════════════════════════════════════

• Needs M1 data: Without M1, High/Low order will be marked "UNKNOWN"
• Historical limitation: Can't reliably analyze candles older than 1-2 months
  (because M1 history is limited)
• Live data: Perfect accuracy for current/recent candles
• Broker dependent: Some brokers have limited M1 history


🔧 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Q: I don't see any lines
A: Set DisplayMode = 0 (Overlay), increase PathWidth to 3-5

Q: Lines are too thin
A: Increase PathWidth (try 3 or 4)

Q: Can't see the dots
A: Make sure ShowPoints = true, increase PointSize to 4-5

Q: High/Low order seems wrong
A: Check if M1 data is available on your broker
  (older candles may show UNKNOWN if M1 data is missing)

Q: Indicator not loading
A: Check console (View → Toolbox → Experts tab) for error messages
