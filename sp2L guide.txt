📋 خلاصه
═════════════════════════════════════════════════════════════════════════════

این اندیکاتور مسیر حرکت قیمت داخل کندل‌ها را نمایش می‌دهد.

مثلاً به‌جای اینکه فقط OHLC ببینی:
  Open=1, High=5, Low=0, Close=3

مسیر واقعی رو می‌بینی:
  1 → 5 → 0 → 3 (اگر High اول باشد)
  یا
  1 → 0 → 5 → 3 (اگر Low اول باشد)


🔧 نصب
═════════════════════════════════════════════════════════════════════════════

1. فایل PricePathAnalyzer.mq5 را کپی کنید
2. مسیر: MetaTrader 5 → File → Open Data Folder
3. پوشه: MQL5/Indicators
4. فایل را اینجا بگذارید
5. MetaTrader 5 را بسته و دوباره باز کنید


📊 استفاده
═════════════════════════════════════════════════════════════════════════════

1. چارت را باز کنید (مثلاً EURUSD)
2. Insert → Indicators → Custom → PricePathAnalyzer
3. تنظیمات را مشخص کنید
4. OK کلیک کنید


⚙️ تنظیمات
═════════════════════════════════════════════════════════════════════════════

Display Mode (نحوه نمایش):
  ├─ 0: Overlay (روی خود چارت)
  ├─ 1: Sub-window (پایین چارت)
  └─ 2: Separate (پنجره جداگانه)

ShowPath (نمایش خط):
  ├─ true: خط رو نمایش بده
  └─ false: خط رو نمایش نده

PathColor (رنگ خط):
  ├─ clrDodgerBlue (آبی - پیشفرض)
  ├─ clrRed
  ├─ clrGreen
  └─ هر رنگ دیگری

PathWidth (ضخامت خط):
  ├─ 1: خیلی نازک
  ├─ 2: نازک (پیشفرض)
  ├─ 3: متوسط
  ├─ 4: ضخیم
  └─ 5: خیلی ضخیم

ShowPoints (نمایش نقاط):
  ├─ true: نقاط O/H/L/C رو نمایش بده
  └─ false: نقاط رو نمایش نده

PointSize (اندازه نقاط):
  ├─ 2: کوچک
  ├─ 3: متوسط (پیشفرض)
  ├─ 4: بزرگ
  └─ 5: خیلی بزرگ

LowerTimeframe (تایم‌فریم پایین‌تر):
  ├─ PERIOD_M1: 1 دقیقه‌ای (بهترین)
  ├─ PERIOD_M5: 5 دقیقه‌ای
  ├─ PERIOD_M15: 15 دقیقه‌ای
  └─ بالاتر: کمتر دقیق

CandlesToAnalyze (تعداد کندل):
  ├─ 1: فقط آخرین کندل
  ├─ 5: آخرین 5 کندل (پیشفرض)
  ├─ 10: آخرین 10 کندل
  └─ بیشتر: تحلیل بیشتر

ShowInfo (نمایش معلومات):
  ├─ true: معلومات رو نمایش بده
  └─ false: معلومات رو نمایش نده


🎨 رنگ‌های نقاط
═════════════════════════════════════════════════════════════════════════════

رنگ‌ها خودکار تنظیم می‌شوند:

  O (Open):  سبز (clrGreen)
  H (High):  قرمز (clrRed)
  L (Low):   آبی (clrBlue)
  C (Close): نارنجی (clrOrange)

خطوط: رنگی که تنظیم دادی (PathColor)


📍 مثال: تایم‌فریم M5
═════════════════════════════════════════════════════════════════════════════

کندل M5 از 10:00 تا 10:05:

OHLC:
  Open:  1.1700
  High:  1.1725 (در 10:02)
  Low:   1.1680 (در 10:04)
  Close: 1.1710

اندیکاتور چه نمایش می‌دهد:

Time    Price    Label
10:00   1.1700   O
10:02   1.1725   H     ← High اول بود
10:04   1.1680   L     ← Low دوم بود
10:05   1.1710   C

مسیر:  O → H → L → C

خط ترسیم شده:
       ┌─H(1.1725)
       │    \
   O   │     \
  (1)─┤      \  
       │       L(1.1680)
       │        \
       │         C(1.1710)


⚠️ نکات مهم
═════════════════════════════════════════════════════════════════════════════

1. اندیکاتور فقط تحلیلی است
   ├─ معامله نمی‌کند
   └─ فقط نمایش می‌دهد

2. نیاز دارد M1 (یا تایم‌فریم پایین‌تر)
   ├─ بدون M1: نتیجه UNKNOWN
   └─ M1 قدیمی: فقط برای کندل‌های اخیر

3. تایم‌فریم اصلی می‌تونه هرچی باشد
   ├─ M1
   ├─ M5
   ├─ M15
   ├─ H1
   └─ D1

4. بروکر باید M1 داده داشته باشد
   └─ بیشتر بروکرها: 1-2 ماه M1 دارند


❌ مشکلات و حل
═════════════════════════════════════════════════════════════════════════════

مشکل: اندیکاتور نمایش نمی‌دهد
──────────────────────────────
  ✓ DisplayMode رو 0 کن (Overlay)
  ✓ ShowPath = true بگذار
  ✓ Console رو بررسی کن (View → Toolbox)

مشکل: خط دیده نمی‌شود
──────────────────────
  ✓ PathWidth رو بیشتر کن (3-5)
  ✓ PathColor رو تغییر بده
  ✓ اینتربار چارت رو refresh کن (F5)

مشکل: نقاط دیده نمی‌شوند
──────────────────────────
  ✓ ShowPoints = true بگذار
  ✓ PointSize رو بیشتر کن (4-5)

مشکل: ترتیب High/Low اشتباه است
─────────────────────────────────
  ✓ LowerTimeframe رو بررسی کن
  ✓ بروکر M1 داده داشته باشد
  ✓ برای کندل‌های قدیمی: نمی‌شود دقیق بود


📖 مثال‌های عملی
═════════════════════════════════════════════════════════════════════════════

مثال 1: Spike بالا رفتن
────────────────────
کندل‌های متوالی با بدنه بزرگ و سایه کم:

  Candle 1: O→H→L→C (بدنه بزرگ)
  Candle 2: O→H→L→C (بدنه بزرگ)
  Candle 3: O→H→L→C (بدنه بزرگ)

نمودار:
  ┌─H
  │ \
  │  L
  │   \
  │    O2
  │    ┌─H
  │    │ \
  │    │  L
  │    │   \
  │    │    O3...

تحلیل: Spike واقعی (هر کندل پیاپی بالا می‌رود)


مثال 2: False Spike (Channel)
──────────────────────
کندل‌های با سایه بزرگ:

  Candle 1: O→H→L→C (سایه بزرگ)
  Candle 2: O→L→H→C (تغییر جهت)

نمودار:
  ┌─H
  │ \
  │  L
  │ / \
  │O   \
  │      L
  │       \
  │        H
  │         \
  │          C

تحلیل: Fake spike (جهت تغییر می‌کند)

4. Strategy testing
   ├─ Verify entry points
   ├─ Check candle patterns
   └─ Understand price movement
